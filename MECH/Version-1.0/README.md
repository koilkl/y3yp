# 🧪 MECH/Version-1.0

First-generation mechanical design of the **Actuation Belt Trainer**.

| File | Description |
|------|-------------|
| [`Gen1-belt.zip`](Gen1-belt.zip) | Zipped STEP assembly (`Gen1-belt.STEP`) of the belt-actuation mechanism — motor-driven belts & gears applying resisted inversion/eversion and dorsiflexion/plantarflexion loads to the pedal |

To view: unzip the archive and open `Gen1-belt.STEP` in any CAD software that supports STEP (SolidWorks, Fusion 360, FreeCAD, etc.).
