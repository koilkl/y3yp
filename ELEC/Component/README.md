# 🧩 ELEC/Component

Reusable, standalone firmware components that support the main system.

| Component | Description |
|-----------|-------------|
| [`Incliometer`](https://github.com/koilkl/Incliometer) | Inclinometer data acquisition & initial-position stability detection (STM32F401RETx / NUCLEO-F401RE, Modbus-RTU over USART1, terminal interface over USART2) |

Each component is a self-contained STM32CubeMX project (a git submodule) with its own README documenting hardware connections, protocol, and usage.
